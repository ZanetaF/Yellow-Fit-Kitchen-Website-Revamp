## About This Project
This project involved redesigning the Yellow Fit Kitchen website with a modern, user-centered interface. The focus was on improving usability, accessibility, and customer engagement by revamping key pages: Home, About, Contact, and Program.


## Technologies Used
- HTML  
- CSS  
- JavaScript  
- Bootstrap CSS (for responsive layout and faster deployment)  

## Project Details
- Conducted heuristic evaluation and user testing to identify UX pain points.  
- Redesigned layout and navigation flow for better accessibility and visual consistency.  
- Developed responsive front-end for the revamped pages (Home, About, Contact, Program) using Bootstrap CSS.
